# Aditay Kumar Das — Portfolio

A modern responsive portfolio website built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files

- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — navigation, theme toggle, scroll animations and form handling
- `assets/profile.png` — supplied professional profile photo
- `assets/Aditay_Kumar_Das_CV.pdf` — supplied CV

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will provide your live website URL.

## Customize

Search for `🔴 EDIT HERE` in `index.html` to find the places intended for customization.

The current version already contains the information from the supplied CV and the supplied profile photo.

### Important privacy note

The National ID number from the CV has intentionally NOT been published on this public GitHub portfolio. A GitHub Pages site is public, and publishing a National ID number can create a serious privacy/identity-theft risk. If you nevertheless decide to publish it, add it only after considering that risk.

## Contact form

The contact form is static by default. To receive messages, replace the form `action="#"` in `index.html` with a Formspree or other static-form endpoint.

## Social links

The Facebook, LinkedIn and GitHub buttons are placeholders. Search for:

`🔴 EDIT HERE — ADD YOUR SOCIAL LINKS`

and replace the `href="#"` values with your real URLs.

## Local preview

Open `index.html` directly in a browser, or use VS Code Live Server for a local preview.
